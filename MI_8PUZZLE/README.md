# JavaProyecto

Proyecto Java básico listo para trabajar en VS Code.

## Requisitos

- JDK instalado y disponible como `java` y `javac`.
- Extensión recomendada: **Extension Pack for Java** (`vscjava.vscode-java-pack`).

## Ejecutar desde la terminal

Desde la carpeta `JavaProyecto`:

```powershell
javac -d out src/main/java/com/ejemplo/App.java
java -cp out com.ejemplo.App
```

También puedes abrir `App.java` y usar el botón **Run** de VS Code.
